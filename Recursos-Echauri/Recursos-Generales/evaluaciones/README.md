# Evaluaciones de favoritos

Cada repositorio favorito tendrá una ficha con:
- repositorio y origen,
- categoría principal,
- propósito,
- estado de prueba,
- puntuaciones 0–5,
- dependencias,
- recursos internos detectados,
- posibles usos,
- notas de compatibilidad,
- enlaces cruzados a categorías visuales del Vault.

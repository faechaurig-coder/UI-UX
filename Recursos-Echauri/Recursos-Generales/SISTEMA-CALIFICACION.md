# Sistema de calificación de favoritos

## Escala por criterio
**0** No evaluable / inexistente  
**1** Muy deficiente  
**2** Limitado  
**3** Útil con ajustes  
**4** Muy bueno  
**5** Excelente / listo para aprovechar  

## Criterios
1. **Funciona** — se puede ejecutar o utilizar realmente.
2. **Instalación** — dificultad para ponerlo en marcha.
3. **Calidad técnica** — estructura, dependencias, errores evidentes.
4. **Reutilización** — facilidad para extraer valor en otros proyectos.
5. **Documentación** — README, ejemplos, instrucciones.
6. **Mantenimiento** — actividad y vigencia.
7. **Compatibilidad Echauri** — utilidad para apps, juegos, IA, automatización o diseño.

## Resultado
No se elimina un favorito porque tenga mala nota. Se clasifica para saber:
- qué conviene usar,
- qué conviene estudiar,
- qué necesita reparación,
- qué sólo sirve como referencia,
- y qué ya quedó obsoleto.

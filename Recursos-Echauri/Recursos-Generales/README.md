# Recursos Generales

Segunda capa del Echauri Asset Vault para repositorios externos/favoritos de GitHub.

## Principio
Cada repositorio favorito se registra como recurso general y se evalúa por su utilidad real. Si contiene assets reutilizables (personajes, UI, escenarios, objetos, audio, VR, etc.), esos recursos se cruzan con las categorías principales del Vault mediante referencias al origen.

## Estado de evaluación
- Sin probar
- Revisado
- Funciona
- Funciona parcialmente
- No funciona
- Obsoleto
- Excelente candidato
- Integrado en proyecto

## Puntuación
Cada favorito tendrá 0–5 en:
- Funcionamiento real
- Facilidad de instalación
- Calidad técnica
- Reutilización
- Documentación
- Mantenimiento/actividad
- Compatibilidad con nuestros proyectos

No se usa una puntuación automática basada sólo en estrellas de GitHub.

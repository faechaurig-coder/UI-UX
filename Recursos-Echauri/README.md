# Recursos Echauri — Asset Vault

Biblioteca central y buscable de recursos reutilizables.

## Principio de seguridad
Este Vault es aditivo. No mueve, renombra, sobrescribe ni elimina archivos de los proyectos originales. Cada registro conserva repositorio, rama, ruta, SHA y enlace al original.

Los archivos binarios privados (PNG, WEBP, GLB, etc.) se indexan de forma segura mediante referencia al original porque el conector de GitHub no entrega sus bytes para duplicarlos. El Vault no intenta reconstruirlos ni transformarlos.

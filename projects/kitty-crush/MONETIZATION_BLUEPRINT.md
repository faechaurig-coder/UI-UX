# WHISKERFOLK — Monetization Blueprint

## Principle
**Monetize identity, expression and expansion of affection. Never monetize neglect.**

## Free experience must include
- complete rescue arcs;
- all core cats obtainable through play;
- core home interactions;
- Catbook;
- Memories;
- functional home customization;
- no mandatory purchase to keep a cat healthy/happy.

## Primary revenue surfaces

### 1. Home Collections
Premium coordinated sets:
- furniture;
- window treatments;
- rugs;
- wall accents;
- interactive cat objects.

Rule: premium sets may be prettier or more expressive, but free objects remain charming and functional.

### 2. Cat Style
- collars;
- tags;
- light accessories;
- seasonal bandanas;
- tiny hats only if animation quality remains high.

Avoid full-body costumes that erase character identity.

### 3. Memory Presentation
Optional:
- premium photo frames;
- album themes;
- animated memory cards;
- share layouts.

The memory itself is never paywalled after it is earned.

### 4. Seasonal Pass
Only after retention is proven.

Structure:
- cosmetics;
- home set progression;
- optional bonus memories;
- no power advantage required.

### 5. Rewarded Ads
Optional only:
- preview alternate decor;
- bonus cosmetic token;
- reroll a cosmetic shop row later.

Never:
- “watch to feed Mochi”;
- “watch or lose streak”;
- forced interstitial after rescue.

## Currency architecture
Keep MVP to:
1. **Soft currency** — earned from puzzles/rescue/home goals.
2. **Premium currency** — later, if commerce validates it.

Do not launch with 5–7 currencies.

## Store UX
- Store is never visible in the first rescue.
- No giant discount banners in Home.
- Product is shown in-context on the cat/home.
- “Try in room” before purchase whenever practical.

## Ethical fail-state policy
Puzzle failure can cost:
- time;
- retry;
- optional strategy change.

It should not exploit emotional attachment:
Never use “Mochi will stay in the rain unless you pay.”

## Revenue validation questions
- Did the player buy because the item expressed taste?
- Did the purchase make Home feel more “theirs”?
- Would they still feel good about the purchase a week later?

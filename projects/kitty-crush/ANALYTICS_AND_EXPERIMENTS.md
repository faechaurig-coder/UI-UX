# WHISKERFOLK — Analytics & Experimentation

## North-star research question
Does the player form a memorable relationship with Mochi before the end of session one?

## Behavioral measures
### Attachment proxies
- seconds observing Mochi with no required input;
- voluntary cat taps that are not goal-driven;
- repeat Catbook opens;
- memory opens/shares;
- placement of objects near cat-favorite zones;
- next-session time-to-first-cat-interaction.

### Puzzle measures
- first move latency;
- invalid swap rate;
- moves remaining;
- retry rate;
- cascade frequency;
- objective comprehension.

### Home measures
- time before opening secondary UI;
- number of autonomous behaviors observed;
- number of object interactions;
- object placement completion.

## Qualitative playtest
After session one ask, without showing prompts:
1. What was the cat’s name?
2. Tell me something about his personality.
3. What moment do you remember most?
4. What do you think Mochi likes?
5. Would you open this tomorrow if no new level reward were waiting?
6. What would you change in his room?
7. Did any part feel like “another match-3”?

## GO thresholds for small prototype study
These are internal decision thresholds, not market guarantees:
- ≥80% unaided Mochi name recall;
- ≥70% can state one accurate personality trait;
- ≥60% choose the Box Moment/rescue as a memorable moment rather than generic puzzle;
- ≥50% say they would return primarily to see/continue with Mochi;
- median ≥30 sec non-required Home observation;
- <20% describe the product primarily as generic match-3.

## Experiment order
A/B only after baseline exists.

1. Box Moment pacing: 12s vs 18s.
2. Direct tutorial vs environmental tutorial.
3. Objective world-change immediacy.
4. Home UI delayed vs immediately available.
5. First object: blanket vs scratcher.

Never A/B core ethical rules.

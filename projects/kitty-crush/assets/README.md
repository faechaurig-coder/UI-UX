# Visual Assets

These assets are **original Whiskerfolk direction assets** created for the vertical slice.

## Files
- `mochi_app_icon_direction.svg` — app-icon/character key-art direction.
- `whiskerfolk_wordmark_direction.svg` — provisional wordmark direction.

## Status
**PRODUCTION DIRECTION — NOT FINAL ART**

They are intentionally usable in prototypes, but the AAA gate still requires:
- final character model/sprite rig;
- expression sheet;
- animation pass;
- art-director review;
- store-size raster exports;
- trademark/name clearance before final wordmark lock.

## Visual invariants to preserve
Mochi:
- cream body;
- caramel right ear;
- caramel comma near one eye;
- moss-green eyes;
- cardboard association;
- cautious rather than permanently smiling expression.

Brand:
- warm milk background;
- deep ink;
- restrained caramel accent;
- subtle whisker/tail logic, not generic paw-print branding.

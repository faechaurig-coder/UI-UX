# WHISKERFOLK — Post-GO LiveOps Outline

This file is intentionally **post-GO**. Nothing here is allowed to delay Mochi validation.

## Cadence concept
- weekly: small Home rotation / photo prompt;
- biweekly: lightweight cosmetic set;
- monthly: rescue chapter or relationship event;
- seasonal: one cohesive room theme + memory set.

## Content pillars
1. New rescue stories.
2. New interactions between existing cats.
3. Home sets.
4. Character memories.
5. Seasonal ambience.

## Best scalable content
Prefer content that reuses systems but creates new emotional combinations:
- one new object can produce 8 cat-specific reactions;
- one new cat can create many pair interactions;
- one room ambience can change behavior weights.

## Avoid
- event calendar overload;
- seven simultaneous countdown banners;
- event-specific currencies everywhere;
- chores disguised as engagement;
- content that expires before casual players can see it.
